# Папка для выгрузки конфигурации 1С

Сюда нужно положить **выгрузку конфигурации 1С в файлы** — это и есть тот
«контекст базы 1С», который чат и агент Cursor будут читать.

## Структура

```
1c-config/
├── src/   ← выгрузка конфигурации (метаданные + модули)
└── ext/   ← внешние обработки/отчёты и расширения (.epf, .erf, .cfe)
```

## Как сделать выгрузку из 1С

### Вариант 1. Конфигуратор (любая типовая, начиная с 8.3.10)

1. Открыть базу в **Конфигураторе**.
2. Меню **Конфигурация → Выгрузить конфигурацию в файлы…**
3. Указать путь — папку `1c-config/src/` этого репозитория.
4. Нажать **Выгрузить**. Платформа создаст дерево XML+BSL.
5. После доработок в Cursor — **Конфигурация → Загрузить конфигурацию из файлов…**
   из той же папки, чтобы вернуть изменения в базу.

> Команды из командной строки:
>
> ```bat
> "C:\Program Files\1cv8\common\1cestart.exe" CONFIG /F"путь_к_базе" ^
>   /N"Администратор" /P"пароль" ^
>   /DumpConfigToFiles "путь_к_репо\1c-config\src" -Format Hierarchical
> ```

### Вариант 2. 1C:EDT (Enterprise Development Tools)

В EDT проект уже хранится в виде файлов. Достаточно скопировать содержимое
проекта (папки `src/` и файлы `.project`, `DT-INF/`) в `1c-config/src/`.

### Вариант 3. Только внешние обработки/отчёты

Если нужно дорабатывать только внешние объекты, положите `.epf`/`.erf` в
`1c-config/ext/`, а рядом — их **исходники** (выгруженные через
`Файл → Сохранить как…` в формате «Файлы» или через
[v8unpack](https://github.com/disa-da/v8unpack) /
[OneScript](https://oscript.io)).

## Как агент будет это читать

- Подключённый MCP-сервер `filesystem-1c` (см. `.cursor/mcp.json`) даёт чату
  и агенту прямой доступ к файлам этой папки — они смогут читать любые
  метаданные и модули как обычные файлы.
- Правила `.cursor/rules/1c.mdc` объясняют агенту структуру и стиль кода 1С,
  чтобы доработки сразу были в стиле платформы.
- Изменения агент будет вносить прямо в файлы `1c-config/src/...`.
  Вам останется только загрузить конфигурацию обратно в базу через
  «Загрузить конфигурацию из файлов…».

## Что НЕ нужно класть в репозиторий

- Файл базы `1Cv8.1CD` (он бинарный и огромный).
- Файлы кэша платформы (`*.cf`, `*.dt`) — кладите только если это релизный
  дистрибутив и он реально нужен.
- Реальные пароли, строки соединения и персональные данные.
